### Documentation

Συμπληρώστε εδώ __όσο documentation χρειάζεται__ ώστε οι βαθμολογητές να
κατανοήσουν πλήρως τις λύσεις σας και να τις βαθμολογήσουν ανάλογα. Αυτό θα
πρέπει να γίνει ανεξάρτητα με το αν ο κώδικάς σας είναι καλά σχολιασμένος,
πράγμα που συνιστάται.

- Άσκηση 1:
  ADTMPQ.c:
  - struct mpq:
    Χρησιμοποιούμε το PriorityQueue ως εσωτερική δομή αποθήκευσης
  - mpq_create:
    Αρχικά δεσμεύουμε μνήμη για το struct της MPQ. Έπειτα δημιουργούμε εσωτερικό PriorityQueue και στο τρίτο όρισμα (Vector) βάζουμε NULL γιατί η ουρά ξεκινάει κενή. Τέλος επιστρέφουμε το mpq
  - mpq_size:
    Επιστρέφουμε το size χρησιμοποιώντας την έτοιμη συνάρτηση του pqueue (pqueue_size)
  - mpq_max:
    Επιστρέφουμε το max χρησιμοποιώντας την έτοιμη συνάρτηση του pqueue (pqueue_max)
  - mpq_insert:
    Εισάγουμε το νέο στοιχείο στην εσωτερική ουρά χρησιμοποιώντας την έτοιμη συνάρτηση του pqueue (pqueue_insert)
  - mpq_remove_max:
    Αφαιρούμε το max χρησιμοποιώντας την έτοιμη συνάρτηση του pqueue (pqueue_remove_max)
  - mpq_merge:
    Αρχικά απενεργοποιούμε τη DestroyFunc της mpq2 για να μην κληθεί χρησιμοποιώντας την έτοιμη συνάρτηση του pqueue (pqueue_set_destroy_value). Έπειτα αποθηκεύουμε το size του mpq2 σε μια μεταβλητή size και καλούμε ένα for loop το οποίο επαναλαμβάνεται size φορές και κάθε φορά εισάγουμε (με την mpq_insert) το μέγιστο της mpq2 στην mpq και το αφαιρούμε από την mpq2. Τέλος καταστρέφουμε το mpq2
  - mpq_set_destroy_value:
    Αλλάζουμε τη συνάρτηση destroy χρησιμοποιώντας την έτοιμη συνάρτηση της pqueue (pqueue_set_destroy_value) και επιστρέφουμε την προηγούμενη
  - mpq_destroy:
    Αρχικά ελευθερώνουμε τη μνήμη για την εσωτερική δομή (pqueue) χρησιμοποιώντας την έτοιμη συνάρτηση pqueue_destroy και μετά ελευθερώνουμε τη μνήμη του ίδιου του struct

  | ΣΥΝΑΡΤΗΣΗ | ΠΟΛΥΠΛΟΚΟΤΗΤΑ | ΕΠΕΞΗΓΗΣΗ |
  | :---: | :---: | :---: |  
  | mpq_create | $O(1)$ | Δημιουργία κενής δομής |
  | mpq_size | $O(1)$ | Επιστροφή του size |
  | mpq_max | $O(1)$ | Επιστροφή του max |
  | mpq_insert | $O(logn)$ | Εισαγωγή και αναδιοργάνωση του heap |
  | mpq_remove_max | $O(logn)$ | Αφαίρεση και αναδιοργάνωση του heap |
  | mpq_merge | $O(mlog(n + m))$ |  Μεταφορά m στοιχείων από την mpq2 στην mpq |
  | mpq_set_destroy_value | $O(1)$ | Αλλαγή ενός δείκτη συνάρτησης μέσα στο struct |
  | mpq_destroy | $O(n)$ | Αποδέσμευση μνήμης για όλα τα n στοιχεία της ουράς |
